## v3.0 — Production Desktop — ЧЕРНОВИК (обсуждение)

> Статус: план формируется на основе анализа конкурентов
> ([COMPETITORS.md](docs/COMPETITORS.md), 2026-09-10). Цель прежняя: лучший
> desktop-клиент для управления несколькими независимыми PVE. «Лучший» =
> быстрее и отзывчивее web GUI, функциональнее всех desktop-аналогов.

### Принцип 0 — перформанс-философия (без этого остальное не имеет смысла)

- **Ни одна задача не блокирует UI-поток.** Любой вызов сети/диска —
  воркер + спиннер/скелетон; ожидание внешнего ресурса никогда не
  проявляется как фриз.
- **Optimistic UI**: действия пользователя применяются к интерфейсу сразу,
  ответ сервера подтверждает или откатывает с понятной ошибкой.
- **Perf-budget как контракт**: границы UI-потока закреплены контракт-тестами
  в CI (не только аудитом); регресс «фриз = баг релиза».
- Ориентиры: холодный старт ≤1 с, клик → реакция ≤100 мс, тяжёлые списки —
  виртуализация.

### Направления (порядок — предмет обсуждения)

1. **Командная палитра (Ctrl+K)** — любое действие с любого экрана
   (старт/стоп/миграция/переход к объекту): меньше кликов, чем у web GUI.
2. **Темы оформления** — тёмная/светлая, системная; спрос доказан
   (PVEDiscordDark ★2540). Токены цветов вместо хардкода Color.*.
3. **Консоли**: SSH-терминал и RDP-лаунчер к ВМ (xterm.js-подобный опыт,
   как у конкурентов) рядом с noVNC/SPICE.
4. **Алерты «Pulse-лайт»**: локальные пороги (CPU/RAM/storage/задачи) →
   тосты/трей; опционально webhook. Мониторинг-платформу не дублируем.
5. **Real-time свежесть**: адаптивный polling (быстрее при активности,
   тише в простое), дельта-обновления таблиц без перестройки дерева.
6. **Платформа**: завершить feature-плагины (Notifications, Policies),
   доменные модели для бэкапов (техдолг из v3.5-списка), стабильный
   внутренний API для будущего расширения.

### Явно НЕ в 3.0 (чтобы не распыляться)

- Мобильный клиент; серверная часть (v4.0); IaC/terraform; дублирование
  Pulse (средства наблюдения уровня его дашбордов).

> Обсудить: приоритет 1–6, perf-бюджет как acceptance-критерий релиза,
> брать ли палитру или темы первыми.
