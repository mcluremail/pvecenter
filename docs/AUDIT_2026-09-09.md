## 🔴 Найдено и исправлено (незакоммичено на момент отчёта)

### E1. `PbsProvider`/`PbsClient` никогда не закрывались
`pbs/workers.py`: каждый `PbsApiWorker` создавал провайдера с
`requests.Session`, но `close()` не существовало ни у `PbsClient`
(`self._http`), ни у `PbsProvider` — TLS-пул утекал на каждый запуск
воркера; `done.emit` не был защищён от `RuntimeError` (закрытое окно).
Исправлено: `PbsClient.close()`, `PbsProvider.close()`, в `run()` —
`finally: provider.close()` + guard. Регресс: `tests/pbs/test_workers.py`.

### E2. Импорт конфига терял `type`/`port`/`proxy`
`config.py:_ALLOWED_IMPORT_FIELDS` не содержал новых полей: PBS-хост после
экспорта→импорта терял `type="pbs"` и превращался в битый PVE-хост
(дефолтный порт 8006, без proxy). Исправлено: `+{"type","port","proxy"}`.
Регресс: `test_import_preserves_type_port_proxy` (roundtrip).

### E3. `WsBridge.stop()` до назначения `_loop` — утечка потока
`ui/console/bridge.py`: `stop()` читал `self._loop` без флага; вызов до
первого присвоения из потока → no-op → поток с сервером жил вечно.
Исправлено: флаг `_stop_requested` ставится безусловно, serve/run_forever
не стартуют при запросе остановки. Регресс: `test_stop_before_loop_assigned_no_leak`.

### E4. `stop()` во время `serve()` — `CancelledError` мимо обработки
Teardown отменял serve-задачу: `asyncio.CancelledError` — `BaseException`,
не ловился `except Exception` → `threading.excepthook` + «Task was destroyed».
Исправлено: явная ветка `except asyncio.CancelledError: pass`; при
`_stop_requested` ошибка старта гасится в `logger.debug`. Регресс:
`test_stop_during_serve_no_unhandled_error`.

### E5. Pin `websockets>=12.0` при требовании кода ≥14
`pyproject.toml` (deps + extra): на 12–13 `connect()` — legacy API с
`extra_headers`; код использует `additional_headers` (≥14). Исправлено:
`websockets>=14.0`, `uv lock` пересинхронизирован (в среде 17.1).

### E6. Catch-all `"vnc" in msg` — ложное «Console not supported»
`backend/console.py`: префиксы `vncproxy:`/`vncwebsocket:` есть в любом
сообщении PVE, поэтому таймаут/сетевой сбой vncproxy маппился в
«консоль не поддерживается». Исправлено: матч только по точным маркерам
(`not supported` / `no console` / `unsupported`). Регресс:
`test_timeout_not_mapped_to_not_supported`, `test_permission_still_mapped`.

### E7. Утечка `NoVncWindow` без `WA_DeleteOnClose`
Каждое открытие консоли оставляло `QMainWindow` + `QWebEngineView` в памяти
(окно не удалялось после close). Исправлено: `Qt.WA_DeleteOnClose`.
Регресс: `test_window_destroyed_on_close`.

### E8. Отклонённые воркеры вечно держали hard/soft-ожидание
`ui/mainwindow.py`: `_run_worker` отклоняет воркер при полном пуле
(`MAX_WORKERS=16`), но `track_hard()` вызывался до запуска → отклонённый
воркер никогда не отчитается → hard-финализация блокируется навсегда
(панель «обновляется» бесконечно). Аналогично `begin_soft(len(active_cfgs))`
считала неотклонённые воркеры → soft-цикл висел до тайм-аута.
Исправлено: `_run_worker → bool`; `track_hard` только после успешного
старта; в soft-цикле capacity-подход (запускаем только влезающие, остаток —
следующий тик; `finish_soft()` при переполнении/пустом списке — попутно
закрыт и 🟡-случай со спиннером при `not active_cfgs`). Регрессы:
`tests/ui/test_refresh_tracking.py`.

### E9. Raw-requests воркеры игнорировали per-host proxy
`ui/api/metrics.py`: 8 воркеров (StorageContent/Backup/Disks, HostNetwork/
Services/Disks/Snapshots, HealthCheck) строили голый `requests.Session()` —
без `cfg["proxy"]`. В proxy-only окружении дерево (через provider) работало,
а все списки/снапшоты/health падали по таймауту. Исправлено: фабрика
`build_requests_session(cfg)` в `provider/_session.py` (явный прокси →
`trust_env=False` + `proxies`; пустой — env-семантика как раньше), 8 мест
переведены на неё. `PbsClient` уже поддерживал proxy — проверено. Регрессы:
`tests/provider/test_requests_session.py`.

### E10. i18n: 7 ключей без переводов + небампнутая версия
Ключи хинтов 595–599 (pveproxy/pvedaemon), `"Proxy:"` и hint прокси
существовали только в ru; `tr("Info")` (заголовок колонки дерева) — ни в
одной локали; `_I18N_VERSION` осталась 28 после добавления ключей →
пользователи не получили бы новые строки. Исправлено: переводы es/fr/ar/zh
для 7 ключей, `"Info"` во все 5, `_I18N_VERSION = 29`. Паритет 1189×6.

### E11. Тесты писали в реальный `~/.config/pve-center/config.sqlite`
`test_tab_order`/`test_lazy_tabs`/`test_storage_content_tabs` (через
`vm_metrics_widget.load_ui_state`) и частично `test_cluster_tasks_widget`
читали/писали пользовательский конфиг. Исправлено: autouse-фикстура
`_isolate_xdg` в `tests/conftest.py` (`XDG_CONFIG/DATA/CACHE_HOME` → tmp).
